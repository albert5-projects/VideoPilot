VIDEOPILOT 0.10.4 - CUSTOMIZABLE VIDEO AND REMOTION GRAPHICS

More English voices:
- Restart: Narrator now lists all 28 installed English voices (20 US, 8 UK).
- Scroll the dropdown; accent and gender appear beside each name.
- No extra downloads or speech-model loading in the GUI.

Editor and editing choices:
- Video tab: choose rules or codex, and capcut or kdenlive.
- Rules: optional gentle slow zoom, pan, float or mixed movement.
- Codex: image-aware editing decisions; the preset movement checkbox is ignored.
- Codex does not freely control the editor GUI; review and export remain manual.
- Enable Remotion and choose coverage in EITHER mode, including Codex.
- Existing uninstalled project: Customize > Apply to current project > Continue.
- Installed project: create an editing revision first.
- Kdenlive needs no CapCut sample. Finish > Open / save Kdenlive project.
- Save in Videos. Keep the VideoPilot media folder and subtitle file available.
- Narrator > Hear 6-second sample. First synthesis takes longer; Stop cancels.
- Small voice caches and existing Remotion packages avoid repeated downloads.

Image repair:
- Finish > Create image repair copy preserves narration and timing in a new project.
- Import corrected images by shot filename, Continue, then install into a new empty project.
- Near-duplicate automatic images with different prompts require review before building.

Missing generated images:
- Restart and click Recover generated images in the Flow tab.
- Open the same Flow project and show the missing images with their full prompt cards.
- Captures use identified image URLs; loading/recycled cards cannot borrow adjacent images.
- Pending imports receive an automatic gallery pass after submissions finish.
- Duplicate warnings trigger rechecking of automatic imports during recovery, with backups.
- Recovery watches for 90 seconds and never clicks Generate.
- After recovery, image checks run before rebuilding. Retry unresolved can spend more generation usage.
- Temporary calibration text is explicitly deleted and checked before prompt entry.

Faster Flow queue:
- In the browser panel choose Submission timing > Every 6 seconds (default).
- Each next click targets six seconds after the previous click, without waiting for images.
- Captured results import immediately in the background, with star cleanup, into images/<shot_id>.png.
- The Flow tab updates its ready count; shot filenames preserve the correct order.
- Recover staged images from older runs: restart, then click Collect Flow downloads.
- Result identities preserve shot order when completion order changes.
- Flow's button availability still controls submissions.
- After stopping, check all unresolved shots before confirming a retry.

Composition update:
- Images and diagrams now share separate regions, with room for captions.
- Graphics enter at approximate spoken cues within each measured scene.
- Type maximum image hold: 0.5-120 seconds, including decimals.
- Stronger star boundary detection and detail-preserving repair when possible.
- Existing installed edits remain protected; create a revision to rebuild.

Quality update:

Already installed? Keep your .venv and models. Close VideoPilot,
run Setup_Flow_Browser.bat once, then restart using Launch.bat or Launch.vbs.

New installation: run Setup.bat and Download_Models.bat first.
Your existing Codex CLI sign-in is reused. VS Code is optional.

1. Create/open a project and prepare narration.
2. Close any VideoPilot browser windows. In Flow images click Open Flow / sign in.
3. Sign into Google in that ordinary browser, then CLOSE that window.
   This browser remembers its own login. Your everyday browser's login
   is separate; it is not copied.
4. Click Run Flow queue in VideoPilot to reopen the saved browser profile.
   Open one Flow project. Choose the two controls in the
   browser panel, confirm Image settings and click Start queue.
5. Keep the app and browser open. Completed images are collected into the
   project and the pipeline continues. No extension is required.
