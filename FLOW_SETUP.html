Repair image assignments without rewriting the video

Near-identical automatic Flow imports with different prompts now require review before a draft is built. See IMAGE_ASSIGNMENT_REVIEW.json. Download the correct Flow results using the filenames in IMAGE_PROMPTS.txt, then use Import images manually. Intentional repeats can be confirmed with Use selected.

Already installed? Choose Finish > Create image repair copy. Script, narration and shot timing are reused in a separate project. Correct images there, click Continue, and install the new draft into a new empty CapCut project. The original edit stays intact.

Remotion clips now record their source image hash. Stale clips must be rebuilt before CapCut export; the storyboard shows current images when graphic provenance is missing or outdated. Flow capture now reads identified image URLs directly and rejects ambiguous or loading card associations.

Choose how your video is edited

  1. Restart VideoPilot. In Video, choose rules or codex, then capcut or kdenlive. All four combinations work.
  2. For rules, optionally enable image movement and choose slow_zoom, pan, float or mixed. These are gentle movements. Still images continue switching with the narration.
  3. Enable Remotion graphics and choose your desired coverage percentage in either mode. Coverage rounds to whole shots; Codex mode also respects it.
  4. Select a narrator and click Hear 6-second sample. First synthesis takes longer. Later playback uses a small local cache; Stop cancels playback or synthesis.
  5. Create your video, review the script, prepare narration and generate/import the Flow images. Continue to build the selected editor project.
  6. For an existing uninstalled project, use Customize graphics / apply changes → Apply to current project → Continue project. A project already handed to an editor needs a revision.

What Codex editing controls

Codex receives contact sheets of the actual images, narration and measured shot timings. It chooses supported camera keyframes, graphic content, emphasis text, transitions, sound cues and audio levels. The preset movement checkbox is ignored. Decisions are stored in editing/edit-plan.json and reused when inputs match. This uses your existing Codex CLI sign-in and additional model requests.

Codex does not freely operate the editor interface or watch and revise playback. Narration and shot boundaries stay fixed. Invalid decisions stop the build instead of silently using presets. Review the result and export in your editor.

Improve your existing video

Start here for the bakery edit or another video already installed in CapCut. Updating the app does not rebuild an installed edit automatically.

  1. Close and restart VideoPilot with Launch.bat or Launch.vbs.
  2. Click Open project and select the original VideoPilot job.json. This is different from CapCut’s draft_content.json.
  3. Go to 3 Finish → Create editing revision. Wait while the app creates a separate project and replans the story into shorter visual ideas.
  4. Open the Script tab. Check that each scene describes one subject or action. Use Save scene after edits.
  5. Click Continue project to generate and measure the revised narration. Generate the new Flow queue; old images are not automatically reassigned to new prompts.
  6. Add sound effects, build the draft, and install into a new empty CapCut project.

The original edit and its media remain intact. Keep both projects until you have reviewed the revision.

Start a new video

  1. In 1 Video, enter your idea, story details, facts and visual preferences. Choose duration, format, narrator and image options per shot.
  2. In Settings, choose captions and sound effects; choose music in Finish. Set a Downloaded sound effects folder before planning if you want its filenames considered. Settings apply to new projects; existing projects retain their saved settings.
  3. Click Create video. The app writes the script, generates local narration and prepares the image queue. Review the script and storyboard as they become available.

What the new editing system does

  • Narration-led cuts: the planner aims for one visual idea per 2–4-second beat, changing on a new subject, action, place or time. Review its interpretation yourself.
  • Your maximum hold: type a value from 0.5 to 120 seconds, including decimals. Five seconds is the default; narration changes can produce earlier cuts. Longer beats receive additional compositions.
  • Tighter audio: sustained near-silence is shortened before image timing is measured. No extra trailing silence is appended. Small differences above or below the requested runtime are accepted: 10%, bounded to at least 2 seconds and at most 15 seconds. A 30-second target accepts 27-33 seconds; a 60-second target accepts 54-66 seconds.
  • Optional image motion: turn on Move images for gentle zoom and pan, or turn it off for static pictures. Image switching follows the same narration timing in both modes.

Your editing reference informed short visual beats, direct cuts and selective effects. Optional Remotion illustrated subjects, processes, comparisons, timelines and relationship diagrams are available below.

Customize image movement, style and Remotion graphics

1. Choose how the images look and move

  1. In 1 Video, type your own description into Image style (type your own). You are not restricted to presets. For example: hand-drawn ink on cream paper with muted orange accents, or photorealistic documentary, soft natural lighting.
  2. Type Maximum image hold in seconds, for example 1.5, 5 or 12. The range is 0.5 to 120 seconds. This is a maximum, not a fixed duration for every image. Narrated idea changes can produce shorter shots.
  3. In rules mode, turn gentle image movement on or off and select slow zoom, pan, float or mixed. Turning it off keeps images static without slowing the cuts. Codex mode chooses camera movement itself.

2. Choose optional motion graphics

  1. Enable Use Remotion graphics, then click Customize graphics / apply changes.
  2. Enter Graphics coverage from 0 to 100. This is the approximate percentage of video runtime containing graphics, rounded to whole shots. For example, 30% of a 60-second video targets about 18 seconds. The log and graphics_report.json show actual coverage. Very small percentages can round to zero shots.
  3. Choose Editorial, Minimal or Bold, and an accent color such as #14b8a6.
  4. The existing Remotion project defaults to C:\Users\alber\vs code projects\mindistry_yt. Browse to another installation if needed. VideoPilot reuses its packages and cached browser; it does not overwrite that project's compositions or install another copy.
  5. For a new video, click Done, then Create video. For an uninstalled existing project, click Apply to current project, then Continue project. For an installed edit, create an editing revision first.

These controls are independent: static photos can have animated graphics, or moving photos can have no graphics. Remotion off or 0% coverage skips rendering entirely. Changing graphics settings alone does not require new Flow images. Changing image style or cut frequency may require new images.

3. Customize the graphic content

With Remotion enabled during planning, the script includes illustrated focus subjects, animated processes, comparisons, timelines or orbit diagrams. Select a scene in the Script tab and click Edit scene graphics to change the layout, title, items and icon names. Keep copy short. Save narration edits before opening this editor, then save the graphic and continue the project. Icons are selected from narration and visual descriptions when missing. Legacy title and steps layouts upgrade automatically; review the chosen symbols for relevance.

Images and graphics occupy separate areas: side-by-side in landscape, stacked in portrait and square. The whole image is contained in its region, so graphics cannot cover it. CapCut captions move into the reserved lower area when graphics are used, while retaining the sample text style. Graphic entrances follow approximate word positions in the measured narration; review the timing. The combined composition is rendered as a silent H.264 clip. CapCut receives those clips in the same shot positions; narration and captions remain separate. Graphic elements are baked into the clips, not separate editable CapCut shapes. Change their text or style in VideoPilot and rebuild before installation.

Rendering and disk usage

Rendering runs one shot at a time with one rendering worker, two encoding threads, bounded media caches and a 1 GB Node heap limit. The browser and encoder also use memory; this is not a 1 GB total-memory guarantee. Remotion starts after local narration has finished. Completed, unchanged clips are reused on resume. Temporary bundles and frames are removed, and superseded verified clips are pruned after a successful uninstalled build. Clips referenced by the current draft or an installed project are retained.

Node.js, matching Remotion 4.x packages and FFmpeg/FFprobe are required when graphics are enabled. Keep the existing installation available. Check the final result in CapCut before exporting; quality depends on your images, graphic copy and chosen settings.

Generate and collect Flow images

  1. Wait until narration is prepared and the Flow queue is ready.
  2. Click Run Flow queue. Open one Flow project tab in the dedicated browser.
  3. In the helper panel, select the prompt control and Generate control. If Generate is disabled, type a temporary word first. Selecting a control does not submit a generation.
  4. Set Flow to Image mode, the displayed aspect ratio and output count. Choose your model and check its usage cost.
  5. Choose Submission timing > Every 6 seconds (the default). Sequential and two/three-in-flight modes are still available. Confirm the settings and click Start queue in the browser panel. VideoPilot replaces the temporary text with the saved prompt.
  6. Keep VideoPilot and the browser open. Avoid unrelated generation or downloads in that tab. Matching images are saved locally and the project continues toward draft preparation.
  7. Use Preview storyboard to check relevance. For alternatives, choose a shot, click View variants, select the variant number and click Use selected.

Capture and import retries

The helper imports images as their identified result bytes arrive, using one background worker. When submissions finish, it automatically scans the gallery for generated results still awaiting import, retries failed reads and checks every shot before completing. Keep the app and Flow tab open during this pass. No extra Generate clicks are sent. Flow loading, verification and missing metadata can delay completion beyond the final generation.

Source URLs are read directly; a recycled image element with conflicting src/currentSrc is rejected. Unfinished captures are retained in a bounded 128 MB spool per queue. Ambiguous results stay unresolved rather than filling a neighboring shot.

Prompt entry now explicitly clears and commits the old editor contents before typing the saved prompt, so the temporary word used to enable Generate is removed. If the editor does not clear, the queue stops before submitting.

Six-second submission timing

The next prompt is prepared and its Generate click is scheduled six seconds after the previous click. Timed mode waits for neither image completion nor request-metadata detection, and has no two/three-shot gate. Results stay linked to their original shot IDs even when they finish out of order. Prompt text stays unchanged.

If Flow disables Generate, shows verification or usage limits, or the next prompt duplicates one still pending, submission can take longer. The log explains the reason and displays actual click intervals. VideoPilot respects Flow's controls. Each captured, identified result is imported into images/<shot_id>.png in the background while other images generate. A single worker validates and cleans each image; the Flow tab updates its ready count. Images keep their original shot filenames even when they finish out of order. To recover staged images from an older run, restart VideoPilot and click Collect Flow downloads before retrying unresolved shots.

Unknown result identities remain unresolved; results are never assigned by arrival order in timed mode. Wrapped/form-encoded requests and delayed metadata are supported. Stop retains captured receipts and every potentially submitted shot. Import finished results before confirming Retry unresolved, which can consume additional usage.

Add sound effects

  1. Download effects through CapCut, or use your existing local sound library. Allow time for CapCut’s online library to load.
  2. Collect accessible WAV, MP3, M4A, OGG, AAC or FLAC files in a folder. You can select C:\Users\alber\AppData\Local\CapCut\User Data\Cache\music directly. Names are recovered from saved CapCut drafts and ID3 titles without renaming cached files. For your own library, use descriptive filenames such as door creak.mp3 or footsteps.wav. The importer reads files directly in the selected folder.
  3. In the new or revised VideoPilot project, choose 3 Finish → Import sound effects and select that folder.
  4. Wait for import to finish, then click Continue project to rebuild.

The app matches recovered names, aliases and filenames against cued scenes and sound descriptions. Import writes SOUND_LIBRARY_CATALOG.csv. The sample teaches VideoPilot your CapCut 2.1.0 format. Do not use the empty destination as the sample.

  2. Choose a readable subtitle style and lower-screen position. Keep the photo full-frame. Do not add keyframes, transitions, animation presets or speed changes to this sample; VideoPilot adds motion to the generated draft.
  3. Save and close CapCut. Choose Finish → Choose CapCut sample and select the sample’s draft_content.json.

Review before exporting

  • Visual meaning: cuts match the narrated subject. If the plan combines different ideas, revise the beats before generating images.
  • Motion: images move gently, fill the frame and keep faces and important objects visible.
  • Audio: listen for awkward pauses, clipped words, music balance and distracting effects. Adjust levels in CapCut.
  • Image cleanup: check for remaining stars, softened repair areas and incorrect subjects.
  • Captions: verify text, placement and timing. Timing is approximate within narration beats, not word-level alignment.
  • Media: check for missing-file warnings and keep the VideoPilot project folder in place.

Reduce disk usage safely

After a successful build, VideoPilot removes byte-identical internal Flow download copies only when those bytes remain in a saved variant. You can also click Finish → Clean duplicate downloads when generation is stopped.

Original variants, selected images, audio, CapCut media, backups, models and browser profiles are retained. External Downloads folders and CapCut caches are not cleaned. The log reports recovered space; zero means no eligible duplicates were found.

Do not move or delete a VideoPilot project folder used by CapCut. CapCut references its media by absolute path. Projects normally live under %LOCALAPPDATA%\VideoPilot\projects.

Troubleshooting

Google says “This browser may not be secure.”

Close the dedicated browser. Use Open Flow / sign in to sign in in ordinary browser mode, close that window, then run the queue. Keep account protections enabled. Google may still reject a session; use ordinary Flow and manual import if it does.

Flow says it is generating, but nothing happens.

Check the selected controls, image mode and verification prompts. Inspect Flow before clicking Retry unresolved; a retry can consume additional usage. If you already have the image, download it and import it under the shot filename. Avoid repeatedly clicking Generate.

An image generated but was not collected.

Use Flow’s native Download control while the controller is watching, or import manually. Automatic collection validates matching PNG/JPEG/WebP files with at least 512 pixels on the short side. Unrelated activity in the same tab can make assignment ambiguous.

“Build the complete draft first.”

Check the project status and Finish log. Click Continue project and complete the requested step: missing images, narration-length adjustment or a valid sample. Install after the draft is ready. The sample contains clips; the destination must be a different, empty project.

“Text schema is unsupported.”

Select a native sample with one plain text clip, one photo and one local WAV. An empty project cannot supply the text format. If it is still rejected, preserve the sample JSON for adaptation; do not overwrite your existing edit.

The old edit still has long holds, pauses or no motion.

Restart the updated app, open the original VideoPilot project and use Create editing revision. Installed edits are protected against regeneration. Opening one alone does not apply the new planner or rebuild its media.

I imported sound effects but cannot hear them.

Import before installation, then click Continue project. Effects only appear on cued scenes; descriptive filenames improve matching. Check the effects track and its volume in CapCut. If FFmpeg is missing, install it and restart VideoPilot.

Scene narration is empty or exceeds 600 characters

This refers to one generated scene, not the length of your idea prompt. Older versions used the same message for blank and oversized narration. The planner now tries one automatic repair. If a previous attempt stopped, restart VideoPilot, open that project and click Continue project. Original generated drafts remain in the planner folder. Narration is never truncated to satisfy the limit.

Can I stop and resume?

Stop retains completed assets. Use Continue project to resume preparation. A possibly submitted Flow shot stays unresolved; inspect Flow before retrying. Create a revision to change an installed edit.
